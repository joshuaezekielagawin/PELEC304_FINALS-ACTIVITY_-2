# Student Enrollment Profile View

## Implementation

A small Django project with one `students` app, SQLite for classroom-ready persistence, a `Student` model, admin registration, seeded demo data, and server-rendered profile routes. The landing page presents a searchable class roster and the selected student profile. The selected profile is addressable through `/students/<id>/`, making each record easy to share and refresh.

## Design

- **Design movement:** Quiet glassmorphism for a calm academic operations workspace.
- **Core principles:** information hierarchy, high-contrast readability, soft depth, responsive utility.
- **Color philosophy:** navy and ink establish trust, lavender/cyan glows make the interface feel contemporary without becoming playful, and mint signals healthy enrollment status.
- **Layout paradigm:** a persistent left rail frames a two-column command center; the roster is a scannable vertical queue while profile content expands into a large translucent canvas.
- **Signature elements:** blurred ambient orbs, frosted panels with hairline borders, and a gradient monogram avatar system.
- **Interaction philosophy:** selecting a student is immediate and reversible; the active roster item echoes the profile accent and tabs expose detail progressively.
- **Animation:** restrained 180–260ms fades and lift transitions, with reduced-motion support.
- **Typography:** Plus Jakarta Sans for interface clarity, with bold display weights for section titles.
- **Brand essence:** Classmate turns enrollment records into a clear daily workspace — composed, attentive, useful.
